SAP Business One OCR Extractor - User Manual

Version: 1.0

Date: July 2026

Overview: The SAP Business One OCR Extractor is an AI-powered automation tool designed to eliminate manual data entry for Accounts Payable (A/P) invoices. It extracts data from scanned invoices or PDFs and automatically posts them to SAP Business One.

1. Dashboard Analytics

The Dashboard is the landing page of the application, providing a high-level overview of system performance and extraction metrics.

Key Features:

  • Metric Cards: View total processed documents, extraction success rate, and pending reviews.
  • Extraction Accuracy Trends: A line chart tracking the AI's OCR confidence over time.
  • Processing Volume: A bar chart showing the number of invoices processed per day.
  • Recent Activity: A live feed of the latest uploaded and posted invoices.

2. A/P Invoice Extraction

This is the core functional area where users upload vendor invoices, review AI-extracted data, and post them to SAP Business One.

Step-by-Step Workflow:

  1. Upload Invoice: Navigate to A/P Invoice Extraction. Click Browse File or drag and drop an invoice file (PDF, PNG, JPG). For bulk processing, select multiple files.
  2. AI Extraction: The system automatically extracts Header Data (Supplier, Date, Totals) and Line Items (Quantities, Prices, Tax Codes).
  3. Review & Validate (OCR Preview): The OCR Raw Text & Confidence sub-tab displays the original text and confidence badges. Low-confidence fields are flagged for manual review.
  4. Logistics & Tax:
    • Switch to the Logistics tab to automatically load the vendor's Ship-To and Pay-To addresses.
    • Switch to the Tax & Compliance tab. If any line item is marked for Withholding Tax (WHT), select the appropriate TDS code. The system will auto-calculate the deduction.
  5. Approve & Post: Once validated, click ✅ Approve & Map, then SAP Post. The system generates a Service Layer JSON payload and creates the A/P Invoice in SAP.
Note: If the SAP posting fails, click the "View SAP Log" button to see the specific error returned by the SAP Service Layer.

3. Document Queue Management

The Document Queue acts as a staging area for all uploaded invoices, tracking their lifecycle status.

Status Workflow:

  • UNPOSTED: Uploaded and extracted, awaiting review.
  • VALIDATED: Business rules (like balancing totals) have passed.
  • APPROVED: User has approved the data; ready for SAP posting.
  • POSTED: Successfully posted to SAP (assigned a DocNum and DocEntry).

Use the Refresh Document Queue button to pull the latest statuses. You can click View / Edit on any row to open that invoice in the Extraction screen.

4. Administration & Master Data

The Admin portal is restricted to users with the Administrator role. It manages system settings, AI configuration, and Master Data synchronization.

4.1 System & API Configuration

Configure the connection to the SAP Business One Service Layer (URL, Company DB, Username, Password) and select the AI OCR Provider (e.g., NVIDIA Llama, OpenAI, Anthropic).

4.2 Master Data Tables

The system maintains local copies of SAP master data for rapid UI population. You can sync data directly from SAP or upload via Excel.

  • Vendors: Contains CardCode, GSTIN, Default Addresses, and WHT Liability settings.
  • Items / Services: SAP Item Master data.
  • WHT / TDS Codes: Defines withholding tax codes, rates, and calculation base.
  • Vendor Addresses: Manages multiple Ship-To and Pay-To addresses for each vendor, used in the Logistics auto-fill feature.

4.3 Form Customization

Enable, disable, or add new Custom Fields (UDFs) to the invoice form dynamically without writing code. These map directly to SAP Service Layer JSON properties.

4.4 Validation Rules Engine

The Validation Rules Engine allows you to create dynamic data governance policies to block invalid invoice postings before they reach SAP.

  • Rule Setup: Target any header or line-level field (e.g., CardCode, DocTotal).
  • Conditions: Define logical conditions (e.g., is_empty, equals, greater_than) and set custom error messages.
  • Enforcement: When a user attempts to approve or post an invoice, the engine evaluates all rules. If a rule fails, the posting is blocked and the error message is displayed to the user.

5. AI Model Training

The AI Training module allows administrators to improve OCR accuracy by feeding historical data back into the AI engine.

How it Works:

  1. Historical Sync: Click Sync from SAP API to download previously posted invoices.
  2. Diff Viewer: The system compares what the OCR originally extracted vs. what the user actually posted to SAP.
  3. Continuous Learning: By analyzing these corrections, the AI updates its extraction rules (e.g., learning that "Inv. No." means "Invoice Number" for a specific vendor).

The Training Accuracy Score gauge provides a visual indicator of the AI's current confidence level across all processed documents.

6. Open Documents Synchronization

The Open Documents module allows you to pull and view pending base documents directly from SAP, such as Open Purchase Orders and Goods Receipt POs.

Using Open Documents:

  1. Sync from SAP: Navigate to the Open Documents tab. Click Sync Open POs or Sync Open GRPOs to fetch the latest documents from SAP.
  2. Filter & Search: Use the search bar or document type dropdown to quickly locate specific documents.
  3. Load into Form: Click Load into Form on any row. This securely transfers the document's header and grid line items (e.g., Cost Centers, Tax Codes) directly into the A/P Invoice Extraction form, providing a fast baseline for matching OCR data.
